scene 02 - sliding extremes

mode

path: lite (0 alloc)

The lite path keeps the window min/max in O(1) via two MonoDeques AND folds the GENERAL rolling sum/mean (cyan) via WindowFold in worst-case O(1) -- the aggregate MonoDeque cannot do -- and never allocates. Below the plot, WindowFoldUint32 folds the same window BITWISE (OR union / AND intersection / XOR parity) -- the register-width sibling a Float64 aggregate cannot honestly carry. The naive path rescans the whole window every frame into fresh O(k)/O(W) arrays -- watch the allocation counter CLIMB as you widen the window.

action

RingLog overwrites its oldest sample forever (lossy, never throws). overflow RingDeque pushes the SAME ring substrate past capacity so it fails closed and shatters red. reset all-time rail clears the MinStack, restarting the stack-lifetime max.

topology

The window is the ONLY place buffers reallocate -- off the frame loop, never inside it. The lite ops/ms stays flat as you slide; the naive rescan climbs.

scene 03 - connectivity + timers

mode

path: lite (0 alloc)

The lite path fires timers off the real HierarchicalTimerWheel and merges each event into UnionFind with 0 alloc/frame. The naive path news one edge object per fired event -- watch the counter climb.

action

overflow TimerWheel schedules past the single-level horizon (delay >= slots) -- it CANNOT be represented, so it fails closed and shatters red. That overflow is why the hierarchy exists. reset islands re-singletons UnionFind.

topology

Each frame HTW may cascade a coarser dial DOWN into the finer wheel on a 256-tick wrap -- the amortized max-single-op spike is architecture, not a stall. TimerWheel (single ring) has no hierarchy to cascade into. CoarseTimerWheel is the third wheel: NEAR-UNBOUNDED (delay to ~2^30, way past TW/HTW) and worst-case O(1) with NO cascade -- a far timer sits in a coarse bucket and fires IN PLACE, LATE by <= gran(level)-1, never early (L0 exact). The far-horizon track plots each timer by log2 ticks-to-fire; the amber marker is peekNext (the next due tick).

scene 04 - priority & sampling

mode

path: lite (0 alloc)

The lite path runs a Dijkstra wavefront off the real BucketQueue (Dial's monotone dial) and answers O(1) "hardest terrain" from an immutable SparseTable with 0 alloc/frame. The casino also runs an AliasTable (Vose) drawing a WEIGHTED loot outcome in worst-case O(1) -- the complement to RandomSet's UNIFORM chip draw; its histogram converges to the target weights. A Reservoir (Vitter R) draws a uniform sample of a fast UNBOUNDED stream in FIXED memory k, and a RankSelect + EliasFano succinct index answers O(1) rank/select/access over a FROZEN bitvector. The naive path news one object per edge relaxation, rebuilds an O(n) cumulative array per weighted draw, BUFFERS the whole stream, and linear-scans the bitvector -- watch the counter climb.

action

decreaseKey below cursor tries to relax a frontier key to a priority under the monotone cursor -- extract order must be non-decreasing, so BucketQueue fails closed and shatters red. That is why the cursor never rewinds. new wavefront re-seeds the source.

frontier

BucketQueue MUTATES every frame (the frontier advances); SparseTable is built ONCE over the FROZEN cost grid and queried forever -- the range query is flat O(1) no matter the width, the mutable vs immutable contrast.
